# 考勤汇总（对话工具）运营说明

## 驻地裁剪与暂定默认

- **花名册驻地优先**：某人花名册「驻地」有值时，出差裁剪一律按该驻地执行。
- **空则暂定太原**：花名册驻地为空时，任务使用暂定默认驻地「太原」参与裁剪（`DEFAULT_BASE_SITE`）。
- **何时撤强制默认**：正式花名册普遍带可靠驻地后，关闭「全员强制太原」类逻辑，仅保留「空则默认」或改为无默认并告警；不得用错误城市静默裁剪。

## 非出勤日打卡

非应出勤日有打卡时产生阻塞告警。对话进度卡可选：

| 动作 | prefer | 效果 |
|------|--------|------|
| 按建议计入 | `present` | 按系统建议半天/全天计入实出勤 |
| 全天计入 | `full_day` | 强制全天 |
| 不计入 | `ignore` | 该日不加实出勤 |

未决议前不可确认正式台账。

## 应出勤（后续规则）

- **现状（V1）**：任务级一套应出勤月历，全员相同。
- **已知例外（待规则化）**：**生产中心**应出勤与其它部门不同。2026-08 正确表为生产中心 26、其它多为 23（张翔宇、靳占鹏）；本期仍豁免，改月历/应出勤规则时必须按中心区分，不得再假定全员同一应出勤。

## 正确表回归

手工例外见 `app/attendance_summary/correct_ledger_exemptions.json`。对比门闩（非豁免须为 0）：

```bash
uv run python _compare_att_xlsx.py --system <系统导出.xlsx> --correct <正确表.xlsx> --fail-on-non-exempt
# 或
ATT_SYSTEM_XLSX=<系统导出.xlsx> uv run pytest tests/test_correct_ledger_gate.py -q
```

规则侧已处理：海外出差出发前驻地打卡误裁、同日裸公司名误标、姓名空格/间隔号归一、打卡地址海外合成出差、**审批断档后外勤打卡仍合成国内出差**等。其余与规格冲突或正确表手改项只进豁免清单。
