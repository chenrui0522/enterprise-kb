## ADDED Requirements

### Requirement: 转换分诊与回退
系统 SHALL 在转换前按格式与文件特征选择转换器，并在所选转换器不可用或失败时按候选顺序回退；分诊结果与最终使用的转换器 MUST 被记录。

#### Scenario: 扫描页 PDF
- **WHEN** PDF 的页面没有可提取文字层
- **THEN** 系统对该页使用 OCR 解析，而不是跳过该页

#### Scenario: 含表格或公式的 PDF
- **WHEN** PDF 被判定包含表格或公式
- **THEN** 系统优先使用表格/公式能力更强的解析器

#### Scenario: 首选转换器失败
- **WHEN** 首选转换器不可用或解析失败
- **THEN** 系统自动尝试下一个候选转换器，全部失败时返回明确错误

### Requirement: 独立解析服务接入
系统 SHALL 支持通过独立 HTTP 服务进行文档转换，服务 MUST 提供健康检查与转换接口；服务不可用时系统 MUST 回退到其他转换器而不是直接失败。

#### Scenario: 解析服务不可用
- **WHEN** 独立解析服务未启动或健康检查失败
- **THEN** 系统跳过该服务并继续使用其他候选完成转换

#### Scenario: 解析服务返回结构化结果
- **WHEN** 独立解析服务返回结构化内容
- **THEN** 系统将其映射为统一的文档结构并进入切片流程

### Requirement: 表格文档语义化
对表格类文档（如 XLSX），系统 SHALL 按工作表分节并逐行生成包含字段名与取值的语义文本用于检索；表格结构信息 MUST 作为元数据保留，且 MUST NOT 与语义文本重复进入索引。

#### Scenario: 多工作表文档
- **WHEN** 用户上传包含多个工作表的表格文档
- **THEN** 每个工作表形成独立章节，并保留工作表名称

#### Scenario: 表头自动推断
- **WHEN** 表格首行可能是表头
- **THEN** 系统推断表头字段名，并把每一行转换为"字段=值"的语义文本

#### Scenario: 超长表格
- **WHEN** 表格行数超过单个切片容量
- **THEN** 系统按行分组切分并重复表头字段名

### Requirement: 转换报告
系统 SHALL 为每个文档版本记录转换报告，包含所用转换器与版本、分诊依据、是否降级、页数、表格数量、图片数量与耗时；报告 MUST 可通过文档状态查询。

#### Scenario: 查看转换报告
- **WHEN** 用户或运维查看某文档版本的处理状态
- **THEN** 系统展示该版本的转换器、降级情况与解析统计

### Requirement: 解析结果缓存
系统 SHALL 以文件内容与转换器标识为键缓存解析结果；当文件内容与转换器均未变化时，系统 MUST 复用缓存而不重复解析。

#### Scenario: 重复入库同一文件
- **WHEN** 同一文件在转换器未变更的情况下被重新入库
- **THEN** 系统复用已缓存的解析结果

#### Scenario: 转换器升级
- **WHEN** 转换器或参数发生变化
- **THEN** 系统重新解析该文件，不使用旧缓存
