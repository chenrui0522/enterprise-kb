## ADDED Requirements

### Requirement: 人员投入路径关键阶段可观测
系统 SHALL 在人员投入（项目日报导入）路径记录结构化运维事件，至少覆盖：解析完成、项目自动匹配、进入待复核、确认写入、作废执行；事件 MUST 可与同一请求标识关联，并在适用时包含耗时（毫秒）与成功或失败状态。运维日志 MUST NOT 写入日报全文；对现场人员自由文本的记录 MUST 截断或仅元数据。

#### Scenario: 解析与确认可串起
- **WHEN** 用户上传日报并成功确认入库
- **THEN** 运维日志中存在带同一请求标识的解析与确认相关事件，且确认事件反映写入或重叠日作废的数量类摘要

#### Scenario: 作废可观测
- **WHEN** 用户按人或按日作废有效出勤事实
- **THEN** 运维日志出现作废事件，包含作废范围类型与作废条数类字段，且带同一请求标识

#### Scenario: 日报正文不入运维日志
- **WHEN** 解析阶段处理含长段「当天实际完成情况」的日报行
- **THEN** 运维日志不出现该完成情况全文
