## ADDED Requirements

### Requirement: 入库携带组织与用途标签
上传与新版本 MUST 持久化所属组织节点、可选项目、专业与密级，并 MUST 将这些标签继承到该版本产生的可检索切片。标签语义与校验 MUST 遵守 `corpus-access`。`doc_type` 等切片策略字段 MUST NOT 被当作组织或密级权限使用。

#### Scenario: 新版本继承标签到切片
- **WHEN** 用户上传新版本且指定组织节点为软件部、专业为软件、密级为一般
- **THEN** 新版本入库完成后其可检索切片携带相同组织、专业与密级，旧版本可检索内容不再参与问答
