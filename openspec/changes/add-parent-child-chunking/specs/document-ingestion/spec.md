## ADDED Requirements

### Requirement: 父子两层分块
系统 SHALL 以 Markdown 标题层级构建父块，并在父块内部递归切分生成子块；父块 MUST 用于生成上下文，子块 MUST 用于检索；每个子块 MUST 记录其父块标识。

#### Scenario: 按标题构建父块
- **WHEN** 文档包含多级标题
- **THEN** 每个标题子树形成父块，并记录章节路径与页码范围

#### Scenario: 父块内部生成子块
- **WHEN** 父块内容超过子块容量
- **THEN** 系统在父块内递归切分生成多个子块，子块携带父块标识

#### Scenario: 超长子树的二级父块
- **WHEN** 单个标题子树超过父块容量上限
- **THEN** 系统在子树内切分二级父块，并保持同一章节路径

### Requirement: 表格独立存储
系统 SHALL 将表格作为独立资产存储（完整表格、表头、行号与章节定位），并在子块中保留可检索的代表内容与引用标记；整表 MUST 可按标识取回。

#### Scenario: 表格入库
- **WHEN** 文档包含表格
- **THEN** 系统存储完整表格资产，并生成包含表头与部分行的可检索子块

#### Scenario: 取回整表
- **WHEN** 用户查看引用中的表格
- **THEN** 系统按表格标识返回完整表格
