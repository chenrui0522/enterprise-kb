## Why

引用区现在已经能显示图片缩略图，但点击只会用新标签打开原图（单张最大约 2.4MB），无法在页面内连续翻看；某文档有多达 352 张图，直接加载原图会拖垮页面。用户需要"在引用区就能浏览图片"。

## What Changes

- 图片读取接口支持 `w` 宽度参数，按需生成并缓存缩略图（Pillow），宽度做白名单/上限约束。
- 引用区缩略图改用缩略图地址并懒加载。
- 点击缩略图在页面内打开 lightbox：放大查看、同一回答内多张图片可连续切换、支持键盘左右与 Esc、点击遮罩关闭；加载失败时保持现有的降级行为。
- 非目标：图片编辑/下载管理、文档级图片画廊（跨文档浏览）、VLM 图片语义描述。

## Capabilities

### New Capabilities
- 无。

### Modified Capabilities
- `image-evidence`: 增加图片缩略图与引用区站内浏览行为（原需求只要求返回可展示的图片标识）。

## Impact

- 后端：`app/api/routers/documents.py` 图片接口增加 `w` 参数与缩略图缓存；缩略图落在本地缓存目录。
- 前端：`frontend/src/pages/ChatPage.jsx` 增加 lightbox 组件与状态，缩略图改为懒加载。
- 测试：新增缩略图接口测试；前端 `npm run build` 验证。
- 数据：无数据库变更。
